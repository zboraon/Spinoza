# Data

## Spinoza.xlsx

Cleaned master dataset of postgraduate theses concerning Spinoza used in
the analyses reported in the manuscript.

Foreign-university records were excluded from the final analytical
dataset. Records referring to Muğla Üniversitesi and Muğla Sıtkı Koçman
Üniversitesi were harmonised as a single institution.

This file is the master dataset used as the denominator in the Bayesian
analyses.

## TPT_ve_PT.xlsx

Subset containing theses classified under the "siyaset" category.

For the Bayesian analyses, records in this dataset are retained only
when their thesis identifier is also present in `Spinoza.xlsx`.
